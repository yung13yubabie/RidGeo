A manual foreground Preview cancels only draft-owned validation before taking shared transport ownership. Manual busy changes refresh drawing controls; drawing cannot start checking during the manual prepare/recalculate pipeline. A drawing confirmation also binds the current plan object, so an intervening manual Apply, Undo or Reset requires a fresh replacement confirmation. Only confirmed drawing Apply enters the existing new-route lifecycle and retires the manual session.

Native39 joined time inputs, 300km duration-width policy, initial manual-panel availability/focus repair and native GPX1.0/1.1 export/imported-proposal reader are preserved. The manual UI intersection adds only an optional busy-change notification. First-plan panel and Preview availability are tested before a terrain-selection helper. Draft checking and confirmation Cancel preserve imported checkpoint proposals; drawn Apply clears them through the existing new-source lifecycle. Actual 301km drawn geometry chooses the long-hour default after Apply while a raw100-hour target remains lossless. Imported exact75-second stops and100-hour cutoffs retain native source meaning.

Persisted pagehide with pending drawing-only inspect/details cancels only that draft work and disposes its shared transport, preserving the accepted plan, ready manual preview and open workout. Generic foreground pagehide behavior is unchanged. The drawing module independently suspends transient pointer/check work and restores draft controls on persisted pageshow. These are simulated lifecycle checks, not evidence of native browser BFCache acceptance.

The protected-entrypoint manifest must be freshly generated from actual protected bytes because the home adds drawing controls, disclosures, stylesheet links and the narrowly added approved map origin. Notices and engine-worker bytes remain unchanged. Both original manifest/build scripts and complete generated-workerd startup gate are preserved and rerun. ## Connected functional path

An explicitly opened public basemap supports a separate Terra Draw LineString draft, finish/edit/insert/delete/undo/redo/clear and scoped keyboard undo/redo. No accepted workspace source, route, CP row, raw stop/cutoff, target opt-in, prediction, workout capture or historical reference is replaced by drawing. Readonly current-GPX reference layers use actual admitted details, original segment boundaries and display-only longitude copies.

The user explicitly requests draft checking. Exact committed original coordinates become GPX in their original order, with no deduplication, rounding, resampling, invented elevation/time or waypoints. The draft retains S2's strict canonical coordinate and generated-midpoint guards. The original shared transport serializes unchanged `inspect` and `details`; there is no second numerical model or dedicated Python worker. Draft validation cannot preempt foreground work, and new foreground work can cancel it. It has no main result ownership. Digest/revision/generation/source/geometry identities reject stale completion, even after undo to identical bytes.

`使用此路線` opens a bounded explicit replacement confirmation. Exact checked bytes are applied only if the draft identity/revision and workspace identity still match. Apply invokes existing `loadBytes`, not direct partial route state assignments. Existing new-route CP/service/target-consent/result clearing and history retention apply. Drawn provenance has its own field, never a fake catalog race. The original GPX download uses those unchanged bytes and the current existing enriched-GPX writer remains the export path.

Generated draft coordinates use exact round-trip decimal spellings, expanding JavaScript exponent notation without numeric rounding. Ordinary generated drafts use GPX1.1. A draft containing exact canonical longitude+180 uses GPX1.0 because the official1.1 schema excludes that value and1.0 includes it; the checked-draft status discloses this format choice. The longitude is never silently rewritten to−180. Official retained schemas validate both generated versions, and actual bundled-WASM raw details preserve exact point order/value, including tiny/subnormal values and legal polar boundaries. Native1.0 enrichment and explicit imported-proposal reread preserve original geometry. This changes only newly generated draft serialization, never an imported GPX. It does not establish physical watch compatibility.

Unknown elevation stays null/unknown. There is no DEM provider, datum conversion, routing or snapping. Original missing-elevation, steep, jump, length, model and export gates remain authoritative. Inspect passes do not imply complete prediction, safe navigation or passable roads. Ordinary missing-elevation goal planning remains blocked until the existing explicit flat-assumption choice is made. No assumption is auto-checked.

## Fixed public map boundary

MapLibre 6.14.0, Terra Draw 1.37.0 and its MapLibre adapter 1.5.0 are pinned local copies from the independently reviewed S2 artifacts. Scripts, shared module, module worker and CSS are same-origin. Original full licenses are distributed under `/drawing/notices/`; assets/dependency lock hashes are recorded in evidence. No package installation, new account, key, location permission, paid plan or remote script is required.

The local minimal vector/text style is independently authored rather than copied from Liberty. Its known OpenMapTiles layer names and Noto Sans Regular glyphs are fixed. It has no raster, sprite, icon or user-specified style URL. The HTML meta, protected Worker response and public asset/module-worker `_headers` policies are synchronized. Only `https://tiles.openfreemap.org` was narrowly added to the existing `connect-src`. Script, worker, image and other CSP directives are unchanged. All MapLibre requests must match the fixed `/planet` TileJSON, dated planet-PBF template or Noto Sans Regular PBF glyph paths; other origins, credentials, queries, hashes and arbitrary paths are rejected. `credentials: same-origin` and `referrerPolicy: no-referrer` suppress cross-origin credentials and referrer. One module map worker and a 128-tile cache cap bound this context; no offline downloader or proxy is introduced.

Drawing controls remain disabled until the loaded source has actual nonempty geographic vector features. A blank grid/background is not offered as a successful map. Failure keeps the admitted workspace intact; initialization failures tear down before retry. No basemap request contains GPX bytes, track timestamps, CP plans, health information or a full route payload. Viewport geography, IP and ordinary request metadata do reach OpenFreeMap/Cloudflare; browser diagnostics such as NEL require native network verification and cannot be ruled out solely by the request guard.

Before loading any public map, the UI provides terms and privacy links plus explicit Enable, limited network-data disclosure and no-SLA notice. Visible linked OpenFreeMap/OpenMapTiles/OpenStreetMap attribution stays outside the canvas and does not depend on map tiles. Using a public basemap is distinct from giving it a route upload or DEM access.

## Cleanup and verification boundaries

New sources/reset remove the old controller, store/history, map canvas/worker, canvas listeners and Blob URLs/timers. Late module/map/digest/worker responses cannot recreate removed ownership. Closing a ready panel cancels transient drawing/check work while retaining the local committed draft; closing during initialization tears down the incomplete map before retry. Persisted page lifecycle suspends/revokes work, then restores actual controls; permanent teardown removes resources. Current renderer identity guards protect late map errors, idle and load callbacks. A WebGL loss keeps the committed draft and requires real geographic readiness after restore.

Source and simulated surfaces cover the original 50,000-point / 25-history / 100,000-history-point budgets and original antimeridian safeguards. Actual hardware responsiveness, GPU resource consumption and native touch are not verified. Legal polar GPX coordinates remain accepted by the existing core; visible Mercator polar authoring is constrained by projection.

Author coverage: actual full application modules and HTML, real distributed Terra UMD and actual integrity-verified Python WASM, with simulated map/container/pointer/worker-delivery surfaces. The independently reviewed core oracle verifies exact geometry, duplicates/loops, antimeridian/poles, admission, 2km/500km/50k and explicit elevation consent. Existing goal correction, CP/source lifecycle, service and admission suites have separately recorded results. A successful production build and source hashes do not establish native browser correctness.

Still required before claiming the map feature complete: actual same-site browser/WebGL tiles and Chinese glyphs under unchanged img-src, local worker startup/MIME/CSP, native drawing/editing/world-copy hit tests, pointer interruptions, keyboard focus, downloads, actual Back/Forward/BFCache, network payload inspection including NEL, narrow/200%/touch and practical large-route performance. Merge with later feature batches requires a new exact combined freeze/review/build. Publication and deployed acceptance are owned by the final combined release.
