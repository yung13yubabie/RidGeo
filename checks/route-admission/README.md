# Cross-provider route admission regression

Run from repository root with Node 22+:

    node --test checks/route-admission/pure.mjs

These 23 portable checks perform no network request, raw GPX read, Python/WASM operation or browser action. They use the real catalogue validator and exact-upload identity index.

Direct import rows must name selected reviewed sources, agree on mandatory URL/hash/source edition, and bind optional non-null edition/bytes/nominal distance/validation bytes. An omitted or explicit null duplicated optional fact remains unknown. Legal display aliases, separate event-landing/course-source pages and information-only rows are controls. Fixed bridge identity and page rules remain strict. Unknown/unselected/duplicate/missing rows and historical promotion cannot pass.

The static semantic gate reuses checks/taiwan-source-adapter/fixture-pins.json. It checks the exact current Taiwan ID set and the existing full source/CP/category hashes without requiring the private raw-original map. Dropped official occurrences and same-length wrong-kind collections must fail. This is a regression test, not a new runtime registry or automatic authority for a changed source. Intentional source/fact changes still need independent qualification and reviewed pin updates. Unknown counts are never inferred from array length.

For a new connected source, also follow docs/contracts/ROUTE-IMPORT-ACCEPTANCE.md, GPX-ADMISSION.md and OFFICIAL-CP-FACT-LIFECYCLE.md, then run the actual source transport and full connected-flow matrix. Passing this configuration test does not prove provider availability, source rights, edition truth, GPX parsing, model eligibility, actual native UI, build or publication.

The maintained 2025 event-card pure/UI suites use the existing strict source-cohort inverse for the later Wufeng2025/Mingfeng2026/HotDog2026 metadata editions. Their original 63-event legacy digest is unchanged; an unknown or altered future edition cannot silently be removed to make a stale count pass.
